# CNPG Extensions Artifacts

Artifacts produced by the [CNPG Extensions](https://github.com/cnpg-extensions)
organization, including official image catalogs for PostgreSQL extensions that
are compatible with CloudNativePG.

The catalog collection is intentionally empty while the initial extension
image catalogs are being prepared. Catalogs will be added under
[`image-catalogs-extensions/`](./image-catalogs-extensions/) as they become
available.
