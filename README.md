# CNPG Extensions Artifacts

Artifacts produced by the [CNPG Extensions](https://github.com/cnpg-extensions)
organization, including official image catalogs for PostgreSQL extension images
that are compatible with CloudNativePG.

Catalog manifests and their associated signatures are published under
[`image-catalogs-extensions/`](./image-catalogs-extensions/).
